🛡️ Email Safety Checker (Phishing Detection Tool)

Developed a rule-based phishing detection system to analyze email content and identify potential security threats using pattern recognition and heuristic scoring.

🔧 Key Features

Built an aggressive content analysis engine to detect phishing indicators such as urgent language, credential requests, and suspicious offers
Designed a dynamic safety scoring system (0–100) with weighted penalties for different threat categories
Implemented multi-layer detection mechanisms, including:
Tone analysis for urgency and social engineering patterns
URL detection to flag embedded malicious links
Text formatting analysis (e.g., excessive capitalization)
Domain validation using a whitelist of trusted MNC domains
Developed an interactive risk visualization bar with real-time feedback (Green → Yellow → Red)

💻 Tech Stack

Backend: Python, Flask, Flask-CORS
Frontend: HTML5, CSS3, JavaScript (Fetch API)
Core Logic: Regex-based parsing and heuristic scoring

📈 Impact / Highlights

Simulates real-world phishing detection logic used in SOC environments
Demonstrates understanding of email threat vectors and social engineering attacks
Built a full-stack security tool with real-time user interaction
